## 需求

新增「系统公告」：管理员在系统管理菜单下维护公告（标题、内容、状态：草稿 / 已发布 / 已下线）；登录后首页顶部显示最新一条已发布的公告，可以关闭。

## 规格要点

目标：管理员需要一个能自己贴通知的地方，不用改代码、不用发版，就能把「今晚维护」「新功能上线」这类信息告诉所有登录用户。用户登录后第一眼（首页顶部）就能看到最新一条已发布公告，看完可以关掉，不挡住首页其他内容。草稿、已发布、已下线三种状态让管理员能先拟稿再放出去，也能随时下线一条说错话的公告。
