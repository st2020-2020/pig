## 需求

系统公告支持查看历史公告：首页公告条上加一个「历史公告」入口，登录用户点开能按发布时间倒序分页看到所有发布过的公告（已下线的也算，草稿不算），点某一条看全文。没有后台菜单权限的普通用户也能看。

## 规格要点

目标：解决"公告只显示最新一条、旧公告被顶掉就再也看不到"的问题。让任何登录用户在首页就能回看系统发过的全部公告正文，不依赖后台「系统公告」菜单权限，也不必再找管理员要内容。
