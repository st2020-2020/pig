# 登录页背景与布局

> 一句话：登录页整页背景换成一张商铺插画 `backgroud.png`，桌面端把登录卡片靠右放，既压不到插画主体，也压不到右下角的小程序二维码。

代码在 main 上（提交 75d1b67，分支 cox/T-9），已合并。

## 业务规则

### 浅色和暗黑共用同一张 backgroud.png，不按主题分支选图

原来有 4 张背景（浅色/暗黑 × 桌面/手机）按 `themeConfig.isDark` 与窗口宽度挑一张，现在统一用 `backgroud.png`。暗黑模式只是换卡片本身的深色渐变，背景图不变。负责人已明确定过这个取舍：宁可暗黑下背景偏亮，也不要维护两套插画。

- 来源：T-9 决定「暗黑模式用哪张背景」；pig-ui/src/views/login/index.vue:59、pig-ui/src/theme/login-layout.spec.ts:189-193

### 桌面端背景贴左按 60vw 定宽，不用 cover 铺满

`backgroud.png` 本体 2158×1196，插画墨迹只占图片宽度的约 61.5%，右侧是透明区。桌面端如果直接 cover 整屏，透明区会一起被放大，插画右边界顶到视口一半以上，卡片无论怎么右移都会压住插画。所以 ≥1280px 时 `.login-bg` 改成贴左、宽 60vw、高按 `calc(60vw * 1196 / 2158)`、`background-size: contain`，墨迹右边界稳定落在视口约 36.9vw 处。

- 来源：pig-ui/src/theme/login.scss:200-229
- 确认人：
- 确认日期：2026-11-16
- 状态：待确认

### 桌面端卡片靠右，右内边距避开右下角二维码

≥1280px 时 `.login-page` 改为 `justify-content: flex-end`、`padding-right: 208px`；≥1536px 加到 232px。卡片宽 560px（`md:w-[560px]`），二维码框 116px + 左右 12px 内边距 + 2px 边框，定位 `right-8`（2xl 为 `right-14`）。这样卡片右边缘与二维码左边缘在 1280/1440/1920 三档下都留 60px 左右间隔，卡左边缘与插画墨迹之间也留 140px 以上。

- 来源：T-9 决定「卡片右移后会撞上右下角二维码，怎么处理」；pig-ui/src/theme/login.scss:231-244、pig-ui/src/views/login/index.vue:15、pig-ui/src/views/login/component/qrcode.vue:2

### 窄屏（<1280px）不右移，仍居中；背景 cover 铺满

右移规则只写在 media query 里，全局作用域不能出现 `padding-right` 或 `flex-end`。移动端卡片 `<768px` 去圆角、去边框、去阴影、白底铺满可用宽度，保证手机上输入框和按钮都在视口内。

- 来源：pig-ui/src/theme/login.scss:285-298、pig-ui/src/theme/login-layout.spec.ts:217-222
- 确认人：
- 确认日期：2026-11-16

### 布局不下架成「看着差不多」，用图片真实墨迹边界算几何

`login-layout.spec.ts` 自己解码 PNG（8bit 调色板 + tRNS，逐行反滤波）算出墨迹右边界比例，再按编译后的 CSS 读出卡片宽度、断点 padding、`.login-bg` 的 60vw、二维码尺寸与 right 偏移，对 1280/1440/1536/1920 四档断言：卡片左边 > 墨迹右边、卡片右边 < 二维码左边、两边间距 ≥24px、卡片不贴死右边缘。布局参数全部从源码读，避免测试里写死一份副本和真实样式脱节。

- 来源：pig-ui/src/theme/login-layout.spec.ts:46-260

## 怎么验证

- 要准备的：能打开登录页的环境（前端已构建、后端可访问），一个可正常登录的账号；不需要特殊权限。
- 主要步骤：
  1. 1440×790、浅色：背景是蓝橙商铺插画，WELCOME/SALE 招牌清晰；卡片在右侧，与插画和右下角二维码都不重叠；计算样式里 `background-image` 指向 `backgroud*.png`，没有 `login-bg*.svg`。
  2. 点右上角主题按钮切暗黑：`data-theme=dark`，背景仍是同一张 png，卡片变深色渐变。
  3. 1280×800、1920×1080：卡片与二维码仍有间隙，插画主体完整，页面无横向滚动。
  4. 390×844：背景铺满，卡片铺满宽度，用户名/密码/登录按钮都在视口内可操作。
- 自动化测试：`pig-ui/src/theme/login-layout.spec.ts`（PNG 解码 + 几何不变式）、`pig-ui/src/theme/login.spec.ts`（样式特异度与颜色）；`cd pig-ui && npm run test`（本机直接跑会失败，见 AGENTS.md「本机环境」）。
