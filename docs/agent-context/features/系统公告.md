# 系统公告

> 一句话：管理员在「系统管理 → 系统公告」里写通知（草稿/已发布/已下线），登录用户首页顶部显示最新一条已发布公告、可以关掉，也能从同一条公告条上的「历史公告」入口回看所有已发布与已下线公告的全文。

主功能在 main（b7a139a，分支 agent/T-11）；历史公告在分支 agent/T-14（db6ce82）。

## 业务规则

### 三种状态：0 草稿、1 已发布、2 已下线

状态是非空单字符，后端用 `@Pattern(regexp="[012]")` 兜住非法值；管理页只按三种状态各自渲染标签（已发布 success、草稿 info、已下线 warning），没有 `v-else` 兜底，非法值一个标签都不渲染，绝不会被当成「已发布」。

### 发布时间只由服务端写，请求体里带的 publishTime 一律丢弃

新增时状态缺省草稿；只有直接建成「已发布」才写 `publish_time = now()`，草稿与下线都写 null。修改时只有「从非已发布变成已发布」才刷新发布时间；改成下线、改回草稿、或本来就是已发布再保存，都置 null 走 `update-strategy=not_null` 跳过该列，库里原值保留，所以下线不会抹掉「它什么时候发过」。**副作用**：没法从请求体指定发布时间，想造「某条发布时间是 2026-11-10 09:00:00」只能直接改库。

## 接口和数据

- `GET /admin/notice/latest`：最新一条已发布公告，没发布过时 `data=null`。**无 `@HasPermission`**，登录即可访问。
- `GET /admin/notice/history/page`：历史公告分页。参数只有 `current`、`size`（`descs`/`ascs` 传了也忽略）；返回 `Page<SysNotice>`，前端只用 `noticeId`、`title`、`content`、`status`、`publishTime`，另有 `total`/`current`/`size`/`pages` 供分页。**无 `@HasPermission`**；**无筛选参数**；**无单独详情接口**。
- `GET /admin/notice/page`：分页，参数 `current`、`size`、`title`（like）、`status`（eq）；不传排序默认 `create_time desc`。权限 `sys_notice_view`。
- `GET /admin/notice/details/{noticeId}`：按主键取一条。权限 `sys_notice_view`。
- `POST /admin/notice` 新增（`sys_notice_add`）；`PUT /admin/notice` 修改，主键不存在返回 `false` 不报错（`sys_notice_edit`）；`DELETE /admin/notice` body 为 id 数组，空数组 no-op 返回 true（`sys_notice_del`）。
- 数据表 `sys_notice`：`title varchar(100)`、`content text`、`status char(1)`、`publish_time datetime`、`del_flag` 逻辑删除，索引 `idx_status_publish (status, publish_time DESC)`。历史公告沿用这个索引，**没有改表结构**。
- 前端封装：`pig-ui/src/api/admin/notice.ts`（首页用 `fetchLatest`，历史用 `fetchHistoryPage`）。
- 种子：菜单 2750（系统公告，parent 2000）+ 2751-2754 四个按钮权限，授权角色 1；i18n 77 = `router.noticeManagement`（`pig/db/pig.sql:443,573-577`）。**历史公告不新增菜单、权限点或路由页**，入口只在首页，种子文件这次没动。

## 怎么验证

- 要准备的：管理员账号（已授权 2750-2754）；一个普通角色账号，**至少授一个可访问菜单**（否则首页白屏，见已知限制），且不授「系统公告」菜单与 `sys_notice_view`；`sys_notice` 里准备已发布 2 条、曾发布后下线 1 条、草稿 1 条、曾发布后改回草稿 1 条、逻辑删除 1 条，最好让可展示公告超过 10 条以便翻页。
- 管理页与公告条：
  1. 「系统管理 → 系统公告」能打开；新建草稿显示灰色标签、发布时间为「—」、添加时间有值；改成已发布后变绿色且发布时间为当前时间。
  2. 标题留空、内容留空分别提交：两个输入框下提示「标题不能为空」「内容不能为空」，且没新增记录。
